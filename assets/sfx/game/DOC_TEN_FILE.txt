Code gọi âm thanh theo TÊN SỰ KIỆN (lúc nào nó kêu), còn file trên đĩa đặt
theo TÊN TIẾNG (nó là tiếng gì). Bảng nối hai cách gọi đó nằm ở
`TEN_FILE` trong scripts/giao_dien/am_thanh.gd.

ĐỔI MỘT TIẾNG: chép file mới vào đây, rồi sửa đúng MỘT dòng trong TEN_FILE
trỏ sang tên file mới. Không phải đổi tên file cũ, không phải sửa code gọi.
